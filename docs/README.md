# Dokumentasi Assistant Reminder

Dokumentasi dipisahkan berdasarkan tujuan agar root repository tetap ringkas.

| Dokumen | Gunakan ketika |
| --- | --- |
| [SETUP_WINDOWS_VSCODE.md](SETUP_WINDOWS_VSCODE.md) | Menyiapkan atau menjalankan proyek di Windows dan VS Code |
| [PROJECT_GUIDE.md](PROJECT_GUIDE.md) | Mempelajari hubungan fitur, API, database, scheduler, PWA, dan worker |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Memahami batas modul dan alur data sistem |
| [TESTING_AND_DEPLOYMENT.md](TESTING_AND_DEPLOYMENT.md) | Menjalankan quality gate dan menilai kesiapan deployment |
| [PHASE_1_IDENTITY.md](PHASE_1_IDENTITY.md) | Mempelajari implementasi akun, sesi, onboarding, dan keamanan awal |
| [PRD_Assistant_Reminder_v2.0.md](PRD_Assistant_Reminder_v2.0.md) | Membaca kebutuhan produk serta keputusan teknis V1 |
| [releases/](releases/) | Melihat petunjuk dan perubahan per versi |

## Aturan dokumentasi

- `README.md` di root adalah pintu masuk proyek.
- Dokumen aktif harus menggambarkan source Next.js yang ada sekarang.
- Catatan versi lama tetap berada di `docs/releases/` dan tidak menjadi instruksi utama.
- Secret, password production, token, dan private key tidak boleh ditulis di dokumentasi atau commit.
